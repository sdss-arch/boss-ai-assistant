站内检索

搜索引擎不收录小红书站内内容。点击按钮会在左侧打开小红书搜索页（用完点「返回 BOSS」即可回来，页面状态不丢），自行搜索后把结果粘贴回来：

  1. 点击「打开小红书搜索」，左侧打开该公司搜索页
  2. 首次使用请扫码登录，然后搜索「公司名 + 口碑/评价/避雷」
  3. 把搜索到的回答、笔记标题复制，粘贴到下方文本框，点「加入尽调证据」
  4. 点「返回 BOSS」回到原来的页面，「开始分析」会优先引用这些站内一手内容

模型

本地模型首次准备（只需一次）

点击「服务配置说明」安装 Ollama，在终端运行 ollama pull qwen3:4b 下载模型（约 2.5 GB）。保持 Ollama 运行，然后点击「读取模型列表」和「测试连接」。模型保存在本机，以后启动服务即可使用；无需重复上传简历。内存较小时可改用更小的模型。

本地模型不收 API 调用费，但需要下载模型并占用本机算力。云端额度、限流和价格由服务商决定；应用不会自动改用付费模型。
