# 路线图

路线图会随社区反馈调整。欢迎在 [Issues](https://github.com/sdss-arch/boss-ai-assistant/issues) 中投票或提出新议题；标记为 `roadmap` 的议题会进入排期讨论。

## v1.1.x · 稳定与治理 ✅（2026-11）

- [x] 从旧仓库迁移并建立独立工程治理体系
- [x] CI / Release / CodeQL / Dependabot 全链路自动化
- [x] 补充贡献指南、安全策略、行为准则、架构与隐私文档
- [x] 真实 Electron 冒烟测试与 148 项自动化测试
- [x] 品牌视觉资产与功能截图

## v1.2 · 体验与可维护性（计划中）

- [x] 设置页支持多 LLM 服务商与自定义 Base URL（Ollama / Gemini / OpenAI 兼容，v1.2 已实现）
- [ ] 提示词模板在线预览与版本管理
- [ ] 岗位匹配支持更多公开职位来源（可插拔采集器）
- [ ] 数据导出格式扩展（Markdown / CSV）
- [ ] 覆盖率报告接入 CI 并逐步提升至 70%

## v1.3 · 协作与效率（探索中）

- [ ] 面试准备卡模板自定义
- [ ] 沟通话术 A/B 记录与效果统计（本地）
- [ ] 简历版本 diff 对比
- [ ] 键盘快捷键与命令面板

## v2.0 · 平台化（愿景）

- [ ] 插件机制：第三方 Agent / Skill 可独立安装
- [ ] 本地模型（Ollama / LM Studio）接入，支持完全离线使用
- [ ] macOS / Linux 构建与跨平台适配
- [ ] 可选的端到端加密同步（用户自持密钥）

## 明确不做

- 自动发送消息、自动投递简历、自动确认面试
- 绕过平台风控、批量注册、验证码破解
- 采集或上传用户未主动提供的私人数据

> 本路线图是计划而非承诺；功能可能根据平台规则与社区反馈调整或取消。
