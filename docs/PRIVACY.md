# 隐私说明

## 原则

本项目遵循「数据最小化 + 本地优先」：所有个人数据默认只保存在你的电脑上，项目本身不设置任何统计上报或遥测服务。

## 数据清单

| 数据 | 存储位置 | 用途 | 是否上传 |
|---|---|---|---|
| 各模型服务 API Key | `%APPDATA%\boss-ai-desktop\settings.json`（各服务独立加密字段） | 调用你配置的大模型服务 | 仅作为请求凭据发往当前配置的服务地址；本机服务可不填 |
| 简历（文本 / 导入文件快照） | 本机配置与版本快照 | 生成招呼语、回复、诊断等 | 任务所需片段会发给所配置的模型服务 |
| JD、聊天片段、公司检索结果 | 内存与本地缓存 | 生成分析结果与报告 | 任务所需片段会发给所配置的模型服务 |
| BOSS / 小红书登录态 | Electron session（本机） | 保持登录，便于读取当前页面 | 否 |
| 面试记录、收藏、Offer | 本机配置 | 工作台展示与导出 | 否 |
| 在线简历原文 / 回填前备份 | 网页内存与本机 `bossAiOnlineResumeBackups`，最多 20 份 | 分段优化、对照与恢复 | 点击优化时将所选原文发往当前模型；回填仅写入 BOSS 编辑框，不自动提交 |

## 本地存储安全

- API Key 使用系统安全存储能力加密，不以明文写入配置文件；配置采用原子写入并保留 `.bak` 恢复副本。
- BOSS 页面注入的脚本只能读取当前页面上下文，无法访问面板设置、API Key 或简历全文。
- 消息发送、简历投递、面试确认等对外动作始终由用户手动完成，应用只负责生成与填入草稿。

## 第三方服务

- **所选模型服务**：手动任务或已开启的自动辅助会将相关简历片段、JD 与聊天片段发送到当前设置的 API 地址。可选择 DeepSeek、OpenRouter、硅基流动、阿里云百炼、Gemini 或自定义服务，受对应服务商的隐私政策约束。请求禁止自动跟随重定向，避免将凭据带往重定向地址。
- **本地模型**：Ollama、LM Studio 等本机服务在本机接收推理内容，应用无需发送至云端模型服务。请确认自行配置的本地代理不会将内容转发至远程；仅免费模式会额外阻止 Ollama 已标识的云端模型。
- **搜索引擎**：公司尽调与风险速查会通过公开搜索结果采集信息，仅使用公开可见内容。
- **BOSS直聘 / 小红书**：应用内嵌或打开这些站点时，遵守其各自的隐私政策与用户协议。

## 如何删除数据

1. 在应用「设置」中清空简历，以及各模型服务分别保存的 API Key。
2. 退出应用，删除目录 `%APPDATA%\boss-ai-desktop`（该目录包含配置、缓存、登录态与历史记录）。
3. 如需彻底清理，请在对应平台的账号设置中撤销登录授权。

## 开发者约定

- 仓库、测试与 CI 中只允许出现虚构占位数据。
- 截图通过 `npm run capture:screenshots` 生成，脚本使用 mock 数据与临时用户目录，不读取真实配置。
- 不得新增任何在未经用户明确同意情况下上传个人数据的功能。

如有隐私问题，请通过 GitHub 私有 Security Advisory 联系维护者。
